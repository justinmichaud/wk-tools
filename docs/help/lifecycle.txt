a board from nothing to an A/B number, as commands
wk help lifecycle -- every command the whole cycle takes, in order, with no
prose between them. Substitute the board and the release; `wk help hardware`
says why the lanes differ and `wk help images` says where an image lives.

RESCUE: the system a board falls back to and is reached by

  wk sysimage build webkit-2.52-yocto-rpi3-32 --detach   # hours
  wk sysimage ls                                         # its path
  wk key tailnet                                         # once per machine
  wk sysimage write --from <path> --disk rpi5 --rescue
      move the card to the board, power on
  wk find rpi3                                           # if it does not answer

  Then it is on the tailnet by name and `wk status` shows it. Nothing else is
  needed: the image carries tailscale, the card carried the key, and first boot
  spent it.

BENCH: the system that is measured

  wk sysimage build wpewebkit-2.38-buildroot-rpi3-32 --detach
  wk sysimage write --from <path> --disk rpi5            # no --rescue
  wk boot rpi3                                           # one shot, self-reverting
  wk pi deploy <workspace> rpi3 --skeleton                # once per board
  wk pi bench rpi3 speedometer3

A/B: two systems, one number each

  wk pi bench rpi3 speedometer3 --ab --count 5
  wk bench ls
  wk bench compare <a> <b>
