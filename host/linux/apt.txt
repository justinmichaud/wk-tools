# Host packages, Ubuntu 26.04. Stock archive only -- no third-party repos.
# Anything a build needs lives in the workspace image, not here.

# Containers, driven by targets/container.sh (wk new/build/test/... with a
# container workspace). Rootless: uidmap provides newuidmap/newgidmap,
# without which no user namespace can be mapped and --userns keep-id cannot
# work.
podman
uidmap

# The interactive shell. shell/bashrc execs zsh when it finds one and silently
# stays in bash when it does not, so without this the two hosts quietly diverge:
# macOS ships zsh as the system shell, Ubuntu does not ship it at all.
zsh

# The WebKit mirror and snapshots (wk sync). ccache is the workspace image's
# own; a shared build box installs its own (remote/provision.sh).
git
git-lfs

# jq: cmd/key and claude/hooks/webkit-jsc-skill-reminder.sh parse JSON with
# it. curl: ./setup --stage tools installs tailscale/zed/claude with it.
# python3: the egress proxy (container/proxy/wk-proxy.py) and every
# JSON/table reader in this repo (stdlib only, no pip).
jq
curl
python3

# perf, for profiling the host's own generic kernel: claude/skills/jsc-marker-trace/capture-perf.sh
# and jsc-profile's samply fallback (claude/skills/jsc-profile/SKILL.md) both shell out to it.
linux-tools-generic

# The pmos image builder (image/pmos.sh), which runs on a Linux aarch64 machine
# over ssh and needs root there. pmbootstrap partitions an image file with
# kpartx and loop devices:
#
#   multipath-tools  carries kpartx, which is the name pmbootstrap asks for --
#                    and the one place where the program and the package are
#                    called different things. It also brings a multipathd
#                    daemon, which no other Linux host here has a use for; it is
#                    installed anyway, because a build host that needs a manual
#                    apt line is not "one command to flash a phone".
#   python3-venv     pmbootstrap is pinned to a git tag in a venv of its own;
#                    every PyPI release of it is yanked
#   xz-utils         the compressed image the store keeps
multipath-tools
python3-venv
xz-utils

# PyYAML, because an image's network configuration is derived from the target
# machine's own netplan rather than copied (image/pmos-build.sh, image/pmos.sh):
# the two ends render it with different backends, and getting that wrong
# produces an image with no network on a board with no cable.
python3-yaml

# GPU and the benchmark session on the attached monitor. cage is a one-client
# kiosk compositor: a real DRM session for benchmark runs without a desktop's
# worth of background compositing noise. wayland-utils' wayland-info is how
# `wk session on/status` tells the session apart from llvmpipe or nothing at
# all: without it, `wk session on` refuses rather than start something
# nobody can verify.
#
# wlr-randr is what makes `wk session off` an output that is off rather than an
# output painted black: cage exports wlr-output-management but ships no client
# for it, and disabling a head through that protocol is the only modeset path
# this driver honours. 11 kB, libc and libwayland-client and nothing else.
cage
wayland-utils
mesa-vulkan-drivers
wlr-randr

# The card writer's media (boot/disk.sh): udisksctl powers a written card off
# so it is safe to pull.
udisks2

# Finding a machine that is not answering to its name (cmd/find).
#
# A node is reached by its tailnet name and how to reach it is not written down
# (CLAUDE.md), which leaves exactly one case open: a machine that is not on the
# tailnet, or is and is not answering, has no address anybody may keep. `wk
# find` sweeps for it instead of remembering, and nmap is the one sweeper --
# there is deliberately no second one, because a fallback chosen by what
# happens to be installed is the path that runs on the machine nobody tested.
nmap
